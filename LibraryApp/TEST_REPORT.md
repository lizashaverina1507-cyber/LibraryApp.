# Отчёт о тестировании LibraryApp

## 1. Объект тестирования
Консольное приложение LibraryApp на C# (.NET 8) – упрощённая система учёта книг в библиотеке[cite: 1].

## 2. Методика тестирования
Использованы три метода: 
* Ручное тестирование (проверка вывода в консоль)[cite: 1].
* Отладка (точки останова, пошаговое выполнение, окна «Локальные» и «Контрольные значения»)[cite: 1].
* Статический анализ кода (анализаторы Visual Studio, уровень `latest-recommended`)[cite: 1].

## 3. Найденные дефекты
| ID | Описание | Шаги воспроизведения | Ожидаемый результат | Фактический результат | Статус |
|:---|:---|:---|:---|:---|:---|
| D-01 | Выдача несуществующей книги приводит к исключению[cite: 1] | Вызвать `BorrowBook(99)`[cite: 1] | Сообщение «книга не найдена»[cite: 1] | `NullReferenceException`[cite: 1] | исправлен[cite: 1] |
| D-02 | Повторная выдача уже выданной книги[cite: 1] | Дважды вызвать `BorrowBook(1)`[cite: 1] | Отказ при втором вызове[cite: 1] | Книга «выдана» второй раз[cite: 1] | исправлен[cite: 1] |
| D-03 | Возврат книги, которая не была выдана[cite: 1] | Вызвать `ReturnBook(2)`[cite: 1] | Сообщение, что книга не была выдана[cite: 1] | Сообщение «Книга возвращена»[cite: 1] | исправлен[cite: 1] |
| D-04 | Можно добавить две книги с одинаковым Id[cite: 1] | Дважды вызвать `AddBook` с Id = 1[cite: 1] | Отказ при втором добавлении[cite: 1] | Обе книги добавлены, вторая недоступна[cite: 1] | исправлен[cite: 1] |

## 4. Результаты инспекции кода
* Устранены предупреждения компилятора и анализаторов (обработка возможных `null`-ссылок, добавление XML-документации)[cite: 1].
* Применены правила именования из `.editorconfig`[cite: 1].
* Методы разбиты на более мелкие логические блоки, избыточный код вынесен в вспомогательные методы[cite: 1].

## 5. Итоги
Приложение полностью работоспособно, граничные случаи обрабатываются корректно, аварийных завершений (исключений) в штатных сценариях больше не возникает[cite: 1].
