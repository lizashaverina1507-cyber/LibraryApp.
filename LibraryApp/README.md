# LibraryApp

Консольное приложение на языке C# (.NET 8), реализующее простую систему учёта книг в библиотеке. Создано в рамках практической подготовки по дисциплине «Инструментальные средства разработки программного обеспечения»[cite: 1].

## Возможности
* Добавление книг с проверкой уникальности идентификатора (`Id`)[cite: 1].
* Поиск книг по `Id`[cite: 1].
* Выдача книг читателям с проверкой доступности[cite: 1].
* Возврат книг в библиотеку[cite: 1].

## Инструкция по запуску
1. Откройте проект в среде Microsoft Visual Studio (начиная с версии 2022)[cite: 1].
2. Соберите решение (`Ctrl + Shift + B`).
3. Запустите приложение клавишей `F5`[cite: 1].
